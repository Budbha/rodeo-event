RODEO EVENT
RODEO EVENT — двуязычный веб-сайт для аренды механического быка и пожарного батута на частные и корпоративные мероприятия в Эстонии.

Сайт знакомит посетителей с услугами, тарифами, условиями аренды и требованиями к площадке. В основе интерфейса — асимметричная Editorial-композиция, фирменная красно-чёрная палитра и сдержанные анимации при прокрутке.

Возможности
- Русская и эстонская локализации с переключением языка без перезагрузки страницы.
- Адаптивная вёрстка для настольных и мобильных устройств.
- Анимации появления элементов и параллакс с учётом prefers-reduced-motion.
- Информация о тарифах: механический бык (почасовая) и пожарный батут (посуточная аренда).
- Интерактивный расчёт стоимости для любого аттракциона или обоих сразу.
- Автоматическая отправка заявок на email `rodeorent1@gmail.com` через сервис Resend с возможностью ручного копирования / открытия почты при сбоях.

Локальная разработка
Для запуска сервера с поддержкой отправки заявок через Resend:
1. Скопируйте `.env.example` в `.env` и укажите `RESEND_API_KEY`:
   cp .env.example .env
2. Запустите сервер:
   npm start
   # или: node server.js
Сайт будет доступен по адресу http://localhost:3000.

Развёртывание на Render
Для полноценной работы отправки заявок через Resend проект развёртывается как **Web Service**:
- **Runtime:** `Node`
- **Build Command:** `npm install`
- **Start Command:** `node server.js`
- **Environment Variables:**
  - `RESEND_API_KEY`: ваш ключ из Resend
  - `TO_EMAIL`: `rodeorent1@gmail.com`
  - `FROM_EMAIL`: `RODEO EVENT <onboarding@resend.dev>`
Также в репозитории подготовлен файл `render.yaml` для автоматического создания сервиса через Render Blueprints.


При подключённом Git-репозитории публикация может выполняться автоматически после обновлений выбранной ветки.
Текущее состояние
Сайт доступен как статический фронтенд. Автоматическая отправка заявок пока не реализована: форма формирует текст заявки для копирования, но не передаёт данные на сервер или электронную почту. Перед коммерческим запуском необходимо подключить обработку заявок и проверить весь сценарий бронирования.

Русская и эстонская версии пока работают на одном URL с клиентским переключением. Для отдельной поисковой индексации языковых версий рекомендуется в дальнейшем предусмотреть самостоятельные URL, hreflang и серверную либо статическую генерацию локализованных страниц.
