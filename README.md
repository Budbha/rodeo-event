RODEO EVENT
RODEO EVENT — двуязычный веб-сайт для аренды механического быка на частные и корпоративные мероприятия в Эстонии.

Сайт знакомит посетителей с услугой, тарифами, условиями аренды и требованиями к площадке. В основе интерфейса — асимметричная Editorial-композиция, фирменная красно-чёрная палитра и сдержанные анимации при прокрутке.
Возможности
- Русская и эстонская локализации с переключением языка без перезагрузки страницы.
- Адаптивная вёрстка для настольных и мобильных устройств.
- Анимации появления элементов и параллакс с учётом prefers-reduced-motion.
- Информация о тарифах, включённых услугах и технических требованиях.
- Интерактивный расчёт предварительной стоимости аренды.
- Форма подготовки заявки и контактные ссылки (mailto: / tel:).
Технологии
- HTML5 — семантическая разметка.
- CSS3 — интерфейс, адаптивность и анимации.
- Vanilla JavaScript (ES modules) — локализация, интерактивность и логика расчёта.
- JSON — словари локализации.
Проект не требует сборщика, фреймворка или установки npm-зависимостей.

Локальная разработка
Для полноценной работы (включая отправку email через Resend):
1. Скопируйте `.env.example` в `.env` и укажите ваш `RESEND_API_KEY`:
   cp .env.example .env
2. Запустите сервер:
   npm start
   # или: node server.js
Сайт будет доступен по адресу http://localhost:3000.

Также можно просматривать статику через `python3 -m http.server 5500` или Live Server (в этом случае при отправке формы сработает резервный режим ручного копирования заявки).

Отправка заявок (Resend)
Заявки с формы автоматически отправляются на адрес rodeorent1@gmail.com.
Подробная пошаговая инструкция по получению ключа, настройке DNS и деплою находится в файле [RESEND_INSTRUCTIONS.md](RESEND_INSTRUCTIONS.md).

Развёртывание на Render
Для работы отправки email проект на Render развёртывается как **Web Service** (не Static Site, так как для вызова API Resend требуется Node.js):
- **Runtime:** `Node`
- **Build Command:** `npm install`
- **Start Command:** `node server.js` (или `npm start`)
- **Environment Variables:**
  - `RESEND_API_KEY`: ваш ключ из Resend
  - `TO_EMAIL`: `rodeorent1@gmail.com`
  - `FROM_EMAIL`: `RODEO EVENT <onboarding@resend.dev>`
Также в репозитории подготовлен файл `render.yaml` для автоматического создания сервиса через Render Blueprints.

Русская и эстонская версии пока работают на одном URL с клиентским переключением. Для отдельной поисковой индексации языковых версий рекомендуется в дальнейшем предусмотреть самостоятельные URL, hreflang и серверную либо статическую генерацию локализованных страниц.
