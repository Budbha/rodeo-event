RODEO EVENT
RODEO EVENT — двуязычный веб-сайт для аренды механического быка на частные и корпоративные мероприятия в Эстонии.

Сайт знакомит посетителей с услугой, тарифами, условиями аренды и требованиями к площадке. В основе интерфейса — асимметричная Editorial-композиция, фирменная красно-чёрная палитра и сдержанные анимации при прокрутке.
Возможности
- Русская и эстонская локализации с переключением языка без перезагрузки страницы.
- Адаптивная вёрстка для настольных и мобильных устройств.
- Анимации появления элементов и параллакс с учётом prefers-reduced-motion.
- Информация о тарифах, включённых услугах и технических требованиях.
- Интерактивный расчёт предварительной стоимости аренды.
- Форма подготовки заявки и контактные ссылки (mailto: / tel:).
Технологии
- HTML5 — семантическая разметка.
- CSS3 — интерфейс, адаптивность и анимации.
- Vanilla JavaScript (ES modules) — локализация, интерактивность и логика расчёта.
- JSON — словари локализации.
Проект не требует сборщика, фреймворка или установки npm-зависимостей.

Локальная разработка
Для загрузки словарей через fetch() требуется HTTP-сервер. Из корневой директории проекта запустите:
python3 -m http.server 5500
Сайт будет доступен по адресу http://localhost:5500.

Также можно использовать Live Server в Visual Studio Code. Открытие через file:// не поддерживается из-за ограничений браузера на локальную загрузку JSON-файлов.
Локализация
Тексты интерфейса хранятся в locales/ru.json и locales/et.json. HTML-элементы связываются с переводами с помощью атрибутов data-i18n и соответствующих ключей.

Язык переключается без перезагрузки страницы. Для прямого перехода к эстонской версии поддерживается параметр ?lang=et.

При добавлении нового текста необходимо обновить оба словаря. Русский текст в HTML служит начальным содержимым и резервным вариантом при недоступности JavaScript; его следует поддерживать в актуальном состоянии.
Расчёт стоимости
Логика расчёта находится в js/booking.js:
- 1–2 часа — 120 € / час;
- каждый час начиная с третьего — 80 € / час;
- фестивали и крупные мероприятия — индивидуальный расчёт.
Доставка по Таллинну включена в стоимость. Условия выезда в другие регионы Эстонии согласовываются отдельно.

Текущее состояние
Сайт доступен как статический фронтенд. Автоматическая отправка заявок пока не реализована: форма формирует текст заявки для копирования, но не передаёт данные на сервер или электронную почту. Перед коммерческим запуском необходимо подключить обработку заявок и проверить весь сценарий бронирования.

Русская и эстонская версии пока работают на одном URL с клиентским переключением. Для отдельной поисковой индексации языковых версий рекомендуется в дальнейшем предусмотреть самостоятельные URL, hreflang и серверную либо статическую генерацию локализованных страниц.
