# RODEO EVENT — Editorial V7 (рефакторинг V6.1)

Это тот же дизайн, анимации, тексты, фотографии и тарифы, что в V6.1. Изменилась **организация кода**, не внешний вид. Никаких библиотек или установки зависимостей для работы сайта не требуется.

## Структура

```text
rodeo-event-clean-v7/
├── index.html          # Семантическая HTML-разметка, без эстонских переводов
├── css/
│   ├── style.css       # Вся стилистика Editorial
│   └── motion.css      # Эффекты появления, градиенты, параллакс
├── js/
│   ├── app.js          # Точка запуска
│   ├── i18n.js         # Загрузка переводов и переключатель RU/ET
│   ├── booking.js      # Калькулятор и черновик заявки
│   └── motion.js       # Анимации прокрутки
├── locales/
│   ├── ru.json         # Весь русский текст, включая формы и уведомления
│   └── et.json         # Весь эстонский текст
└── assets/             # Логотип и исходные фото аттракциона
```

## Как открыть в VS Code

1. Распакуйте ZIP.
2. Откройте **всю папку проекта** в VS Code.
3. Установите расширение **Live Server** (Ritwick Dey).
4. Нажмите правой кнопкой на `index.html` → **Open with Live Server**.

Важно: **не открывайте `index.html` двойным кликом** (`file://`). Переводы загружаются через `fetch`, который браузеры обычно блокируют в таком режиме. Нужен Live Server или любой локальный HTTP-сервер.

Альтернатива: откройте терминал в папке проекта и запустите `python -m http.server 5500`, затем перейдите на `http://localhost:5500/`.

## Как редактировать переводы

- Русский текст → `locales/ru.json`
- Эстонский текст → `locales/et.json`

В HTML вместо переводов стоят ключи, например `data-i18n="hero.lead"`. Для placeholder, alt и aria-label предусмотрены отдельные ключи. Кнопка RU/ET переключает содержимое без перезагрузки. Ссылкой `/?lang=et` можно сразу открыть эстонский язык.

**Почему в HTML всё ещё виден русский текст:** это запасной текст на случай, если JavaScript не загрузится, а также начальное содержимое страницы. На работающем сайте текст подставляется из `ru.json`/`et.json`. Если меняете русский текст, для синхронности no-JS версии обновите соответствующий фрагмент в HTML или сообщите об изменении при следующем обновлении — в дальнейшем можно автоматизировать сборку HTML из словаря.

## Как менять конкретные вещи

- **Цвета, размеры, сетка** — `css/style.css`. Основные цвета в `:root`.
- **Плавность появления и параллакс** — `css/motion.css` + `js/motion.js`.
- **Расчёт 120 €/час и дополнительных часов по 80 €** — функция `calculatePrice()` в `js/booking.js`.
- **Тексты тарифов** — `locales/*.json`, раздел `pricing`; видимые числа в HTML находятся в элементах `.tariff-price`.
- **Фотографии** — `assets/bull-front.webp` и `assets/bull-angle.webp`. При замене соблюдайте прежние имена, форматы и желательные пропорции.
- **Форма бронирования** — `index.html` и `js/booking.js`.

## Загрузка на Render (Static Site)

В GitHub загрузите **содержимое** папки проекта (чтобы `index.html` лежал в корне репозитория), включая `css`, `js`, `locales`, `assets`.

- Service: **Static Site**
- Root Directory: пустое
- Branch: `main` (или ваша текущая ветка)
- Build Command: `echo ready`
- Publish Directory: `.`
- Auto Deploy: On Commit

После обновления GitHub Render опубликует новые файлы. Удалите старые версии `styles.css`, `motion.css`, `app.js`, `motion.js` из **корня** репозитория, если они ещё остались: теперь нужные файлы лежат в своих подпапках.

## Ограничения перед запуском для клиентов

- Форма **не отправляет** заявки; она только создаёт текст для копирования. Ей потребуется серверный обработчик или сервис форм. Не представляйте её как работающую онлайн-отправку.
- Фестивали рассчитываются индивидуально; доставка по Таллинну включена, остальные города — по договорённости.
- Русская и эстонская версии пока работают через один URL с клиентским переключением. Для полноценного SEO по двум языкам лучше позже сделать отдельные `/ru/` и `/et/` со статически подготовленными страницами и `hreflang`.

## Что было проверено

- Синтаксис JavaScript.
- Совпадение ключей RU/ET с ключами в HTML.
- Визуальное отображение (изолированный Chromium-просмотр) без горизонтальной прокрутки на 390, 1280, 1920 и 2560 px.
- Переключение RU↔ET, выбор 4 часов (400 €), фестивальный расчёт и формирование черновика заявки.

Тестовый Chromium в текущей среде не разрешает прямую навигацию по локальному URL, поэтому визуальная проверка выполнялась в изолированном HTML-предпросмотре с теми же CSS, JS и изображениями. После загрузки на Render стоит дополнительно пройти сайт в обычном браузере.
